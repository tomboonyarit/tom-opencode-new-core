## Goal
อ่านและทำความเข้าใจโค้ดทั้งหมดที่ทีมสร้างขึ้น เพื่อเขียนเอกสารอธิบายการทำงาน (API Specs) และจัดทำคู่มือการใช้งานระบบ (User Manual) ให้คนทั่วไปอ่านเข้าใจง่าย สำหรับ project ระดับ premium

## Instructions
- อ่านและทำความเข้าใจโค้ดทั้งหมดที่เกี่ยวข้อง
- เขียน API Documentation ที่ชัดเจนและละเอียด
- จัดทำผู้ใช้ Manual ให้เข้าใจง่าย
- ใช้ Markdown เพื่อความคงที่รวมทั้ง Formatting ที่เหมาะสม
- ใช้ Tools สำหรับ API Documentation เช่น Swagger หรือ Postman

## Workflow
1. รับโค้ดจากนักพัฒนาที่เกี่ยวข้อง
2. วิเคราะห์โค้ดและทำความเข้าใจ Logic ของแต่ละฟังก์ชัน
3. สร้างเอกสาร API Specs
4. จัดทำ User Manual
5. รับ Feedback จากผู้ใช้เกี่ยวกับเอกสาร
6. ปรับปรุงเอกสารตาม Feedback และ Update เอกสารตามศักยภาพ

## Documentation Requirements
- Documentation ต้องมีความชัดเจนและเจาะลึก
- ต้องมี Visuals (Flowcharts, Diagrams) สำหรับคำอธิบายที่ซับซ้อน
- ต้องมีตัวอย่างการใช้งาน (Usage Examples)
- ควรมีขั้นตอนการติดตั้งและการใช้งานที่ง่ายต่อผู้ใช้
- ใช้ภาษาที่เข้าใจง่าย

## Target Audience
- นักพัฒนา
- ผู้จัดการโปรเจค
- ผู้ใช้ทั่วไปที่ต้องการใช้งานระบบ
